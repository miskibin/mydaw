2WAVE — selekcja jako kontekst, 3 poziomy widoku efektu · 1920×1080

Na ekranie widać całą hierarchię naraz: chip (pasek łańcucha, dół Inspectora) → karta mini (EQ Eight / Compressor, Saturator collapsed = sam nagłówek + bypass) → okno pływające (pełny UI EQ Eight, title bar „EQ Eight — Lead”, resize + 2×klik na title bar = maximize). Okno żyje niezależnie od selekcji.
Bez powtórzeń: miernik mastera z belki górnej wycięty — na górze zostały liczby (peak / LUFS), realny miernik jest raz, na strippie Master. Skala dB jest raz, po lewej stronie miksera, nie na każdym kanale. Fader i pan tylko w mikserze; Inspector trzyma tor sygnału. S / M / kropka-arm mają jedną semantykę wszędzie — mute na Chords wygasza też jej klipy w timeline. Grupa DRUMS jest zwinięta w jeden pas (3 ścieżki) zamiast tabu GROUPS dublującego listę.

1DAW shell — FL logic, modern docked shell · 1920×1080

Assumptions: single-window, docked panels, tabbed bottom editor. Pattern-first: the Channel Rack owns instruments + step patterns, the Playlist arranges pattern clips and audio on a linear timeline. Plugin GUIs are separate native windows — the shell reserves screen real-estate and a dock/parking rail for them rather than embedding. Dev-first: everything has a keyboard route, panels show real numbers (samples, PPQ, CPU, buffer), no hand-holding. Type is IBM Plex Sans + Plex Mono; single hue-wheel track palette at fixed lightness so clips read as one family.
